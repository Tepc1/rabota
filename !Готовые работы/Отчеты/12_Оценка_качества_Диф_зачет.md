## 12.3. Подготовка к демонстрации на зачёте

Порядок демонстрации ИС:

1. Развёртывание БД: SQL-скрипты 01 → 05 (создание, таблицы, импорт JSON, индексы, данные).
2. Запуск AutoCenterPlus.Client, вход admin/Admin123 — демонстрация справочников и расчёта стоимости заказа.
3. Вход manager/Manager123 — формирование отчёта «АнализЗаказовКлиентов», сценарии скидок 0 / <20 / >20 %, строка ИТОГО, зелёное оформление.
4. Вход operator/Operator123 — демонстрация RBAC (скрытые пункты, отказ в отчёте).
5. Запуск AutoCenterPlus.Api (Swagger) — запросы коллекции Postman TC-08…TC-13.
6. Скрипты 06–08 — обновление структуры, файловые группы, backup/restore.
