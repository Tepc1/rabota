# Раздел 11. Устранение замечаний по документации

**Тема:** Автоцентр «Плюс»

## 11.1. Источник замечаний

Замечания выявлены в ходе внутреннего (Раздел 9) и экспертного (Раздел 10) тестирования, а также при проверке проектной документации.

## 11.2. Протокол замечаний и их устранения

| № | Замечание | Причина | Способ устранения | Статус |
|---|---|---|---|---|
| З-01 | В Заказчики.json ключ адреса — «addres» (опечатка), у части записей пустой ИНН | Исходные данные | Импорт через OPENJSON с маппингом '$.addres' и NULLIF(INN,'') | ✅ устранено |
| З-02 | Модуль расчёта стоимости не учитывал Quantity | Логическая ошибка эталонного модуля | Переход на v_OrderFullCost (TotalPositionCost = Quantity × стоимость ед.) | ✅ устранено |
| З-03 | SQL-инъекция в запросе стоимости заказа | Конкатенация строк | Параметризованный запрос @OrderId во всех модулях | ✅ устранено |
| З-04 | Падение приложения при нечисловом ID и при сумме 0 | Отсутствие валидации и проверки знаменателя | int.TryParse; проверка totalCost > 0 | ✅ устранено |
| З-05 | Утечки соединений и ридера | Нет using | using для SqlConnection/SqlDataReader/SqlCommand | ✅ устранено |
| З-06 | Замедление расчёта при росте объёма данных | Скалярные подзапросы | VIEW v_OrderFullCost с OUTER APPLY + индексы | ✅ устранено |
| З-07 | В ТЗ и ER-диаграмме не описана таблица скидок | Документация отставала от реализации | CustomerDiscount и v_ClientOrderAnalysis внесены в документацию (ТЗ Ф5, ER) | ✅ устранено |
| З-08 | Пароли в отчёте упомянуты в открытом виде | Черновик | Убраны; указаны только логины (пароли — SHA-256 + соль в БД) | ✅ устранено |

## 11.3. Верификация устранения

После внесения исправлений повторно выполнены:

- тесты TC-02…TC-13 (все пройдены);
- экспертные сценарии ЭТ-01…ЭТ-06 (все пройдены);
- повторный статический анализ SonarLint — предупреждения CA2000/CA2100/CA2213 в исправленных модулях отсутствуют;
- регенерация документации (Разделы 2, 3) — приведена в соответствие реализации.

## 11.4. Выводы по разделу

Выявлено и устранено 8 замечаний трёх категорий: ошибки кода (З-02…З-05), производительность (З-06), документация и данные (З-01, З-07, З-08). Все исправления верифицированы повторным тестированием; регрессий не выявлено.
