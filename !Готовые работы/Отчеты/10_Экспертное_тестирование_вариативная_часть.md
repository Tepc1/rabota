## 10.1. Задание вариативной части

Разработать модуль отчёта «АнализЗаказовКлиентов» по требованиям КИМ 09.02.07-5-2027:

| № | Требование |
|---|---|
| 10.2 | Колонки DataGridView: Клиент, Товары (работы, услуги), Код, Кол-во, Ед., Цена, Скидка, Сумма |

## 10.2. Реализация

**Данные:** VIEW v_ClientOrderAnalysis (SQL/10_ClientOrderAnalysis.sql) — соединение заказов, позиций, продукции, спецификаций с OUTER APPLY по материалам и операциям; цена за единицу = Σ(цена × норма); скидка — из таблицы CustomerDiscount.

**Форма ClientOrderReportForm:**

- фильтр по клиенту — ComboBox, пустое значение = все клиенты (параметр @Client IS NULL);
- вывод в DataGridView по колонкам п. 10.2;
- % скидки — служебный столбец DiscountPercent; при сумме = 0 → 0 % (защита от деления на ноль);
- строка «ИТОГО»: Σ скидок, Σ сумм, % = (Σ скидок / Σ сумм) × 100 (средневзвешенный, а не среднеарифметический);
- условное оформление через CellFormatting: при % > 20 — зелёный фон ячеек «Скидка» и «Сумма»;
- RBAC: при роли ≠ Manager — сообщение и закрытие формы; кнопка «Сформировать» блокируется на время запроса (10.7);
- пустая выборка → информационное сообщение «Данные отсутствуют».

**API-аналог:** GET /api/orders/analysis?client= — возвращает items + total (discount, sum, discountPercent).

## 10.3. Сценарии экспертного тестирования

Подготовлены данные скидок (10_ClientOrderAnalysis.sql):

- ООО «Фермер» — скидка ~4 % (< 20 %, без оформления);
- ООО «Ромашка» — скидка > 20 % (зелёное оформление);
- ООО «Ассоль» — скидка 0 руб. (проверка деления на ноль).

| ID | Сценарий | Ожидаемый результат | Статус |
|---|---|---|---|
| ЭТ-01 | Вход под Operator, открытие отчёта | «Недостаточно прав», форма закрыта | ✅ |
| ЭТ-02 | Вход под Manager, формирование без фильтра | Все клиенты, строка ИТОГО, корректные суммы | ✅ |
| ЭТ-03 | Фильтр по ООО «Ромашка» | Скидка > 20 % → строки выделены зелёным | ✅ |
| ЭТ-04 | Фильтр по ООО «Ассоль» (скидка 0) | 0 %, без ошибок деления | ✅ |
| ЭТ-05 | Фильтр по несуществующему клиенту | «Данные отсутствуют», пустая сетка | ✅ |
| ЭТ-06 | Повторное нажатие «Сформировать» во время запроса | Кнопка заблокирована, повторный запрос не отправляется | ✅ |

## 10.4. Выводы по разделу

Модуль «АнализЗаказовКлиентов» полностью соответствует требованиям вариативной части: все колонки, формула % скидки, строка ИТОГО (средневзвешенный процент), условное оформление > 20 %, RBAC по роли «Менеджер», защита от повторных нажатий и деления на ноль. 6 экспертных сценариев пройдены.
