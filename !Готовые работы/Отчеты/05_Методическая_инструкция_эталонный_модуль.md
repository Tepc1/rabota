# Раздел 5. Методическая инструкция. Эталонный модуль с ошибками

**Тема:** Автоцентр «Плюс»
Материалы: `Проекты/AutoCenterPlus.IS/Раздел5_Эталонный модуль с ошибками (до исправления)/OrderForm_Before.cs`

## 5.1. Постановка задачи

От руководителя практики получен «эталонный» модуль `OrderForm_Before.cs` (расчёт полной стоимости заказа покупателя) с намеренно внесёнными ошибками. Требуется:

1. провести статический анализ (VS2022, SonarLint) и отладку;
2. идентифицировать и классифицировать ошибки;
3. исправить модуль (см. `AutoCenterPlus.Client/Forms/OrderForm.cs`);
4. оформить протокол исправлений.

## 5.2. Протокол выявления ошибок кодирования (8 ошибок)

| № | Тип ошибки | Диагностика | Описание |
|---|---|---|---|
| 1 | Утечка ресурсов | CA2213 | SqlConnection объявлен полем и никогда не закрывается |
| 2 | Отсутствие обработки исключений | Отладчик | int.Parse без проверки → FormatException при вводе "abc" |
| 3 | SQL-инъекция | CA2100 | Конкатенация строки запроса вместо параметризации |
| 4 | Некорректный SQL | Ошибка выполнения | Обращение к несуществующей таблице ProductPrice |
| 5 | Логическая ошибка | Тестирование | Стоимость считалась БЕЗ учёта Quantity — итог занижен |
| 6 | Некорректная работа с соединением | InvalidOperationException | Повторное Open() открытого SqlConnection |
| 7 | Утечка ресурсов | CA2000 | SqlDataReader не закрыт (нет using) |
| 8 | Деление на ноль | DivideByZeroException | Расчёт процента скидки без проверки знаменателя |

## 5.3. Методика исправления

| № ошибки | Исправление |
|---|---|
| 1, 7 | using для SqlConnection и SqlDataReader — гарантированное освобождение ресурсов |
| 2 | int.TryParse с валидацией ввода и информированием пользователя |
| 3 | Параметризованный запрос @OrderId вместо конкатенации |
| 4 | Запрос к корректному объекту — представлению v_OrderFullCost |
| 5 | Расчёт через TotalPositionCost = Quantity × (материалы + операции) |
| 6 | Соединение открывается один раз, закрытие через using |
| 8 | Проверка totalCost > 0 перед делением |
| общее | try/catch (SqlException, Exception) с понятными сообщениями пользователю |

## 5.4. Результат исправления

Исправленный модуль — `AutoCenterPlus.Client/Forms/OrderForm.cs`:

- параметризованный запрос к VIEW v_OrderFullCost;
- using для всех IDisposable;
- валидация ввода (TryParse);
- защита от деления на ноль;
- обработка SqlException и общих исключений;
- вывод полной стоимости в денежном формате и процента скидки.

Код «до» и «после» сравнивался построчно; эталонный модуль с ошибками хранится отдельно и не включён в сборку решения.

## 5.5. Выводы по разделу

В ходе статического анализа и отладки выявлено и устранено 8 ошибок трёх классов: ресурсы (1, 6, 7), безопасность (3), корректность бизнес-логики (2, 4, 5, 8). Исправления подтверждены тестами внутреннего тестирования (Раздел 9): TC-06 «буквы вместо цифр» и TC-07 «деление на ноль» проходят без падения приложения.
