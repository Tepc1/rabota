# Раздел 2. Проектная документация. Техническое задание

| Язык запросов | T-SQL |

## 2.2. Назначение и цели создания ИС

**Назначение:** автоматизация учёта заказов, расчёта полной стоимости услуг, ведения справочников и анализа заказов клиентов автоцентра.

**Цели:**

1. Снижение трудоёмкости расчёта стоимости заказов.
2. Исключение ошибок ручного расчёта норм расхода материалов и трудоёмкости.
3. Формирование отчётности «АнализЗаказовКлиентов».
4. Разграничение прав доступа (RBAC).

## 2.3. Требования к функциональности

| № | Требование |
|---|---|
| Ф1 | Ведение справочника заказчиков (просмотр, добавление, редактирование, удаление) |
| Ф2 | Ведение справочников продукции, материалов, операций, спецификаций |
| Ф3 | Оформление заказов покупателя с позициями и количеством |
| Ф4 | Расчёт ПОЛНОЙ стоимости заказа с учётом количества продукции, стоимости всех материалов и технологических операций с нормой расхода |
| Ф5 | Отчёт «АнализЗаказовКлиентов» с расчётом % скидки, строкой «ИТОГО», условным оформлением |
| Ф6 | Идентификация и аутентификация пользователей, разграничение ролей |
| Ф7 | REST API для доступа к данным (клиенты, стоимость заказов, анализ) |
| Ф8 | Логирование действий и ошибок |

## 2.4. Требования к структуре БД (3НФ)

- Единая схема именования: таблицы — единственное число, PascalCase, PK = Id, FK = <Таблица>Id.
- Все таблицы нормализованы до 3НФ.
- Ограничения целостности: PRIMARY KEY, FOREIGN KEY, UNIQUE, CHECK, DEFAULT.
- Пароли хранятся только в виде хеша (SHA-256 + соль).

## 2.5. Требования к надёжности и сопровождению

- Резервное копирование: FULL (еженедельно), DIFF (ежедневно), LOG (каждые 2 часа).
- Тестовое восстановление из резервной копии не реже 1 раза в неделю.
- Обновление структуры БД без потери данных.
- Обработка исключительных ситуаций во всех модулях.

## 2.6. Требования к программному обеспечению

- ОС: Windows 10/11 или Windows Server 2019+.
- СУБД: MS SQL Server 2019+ (для OPENJSON — SQL Server 2016+).
- .NET SDK 8.0, Visual Studio 2022.
- Postman (для тестирования API).

## 2.7. Выводы по разделу

ТЗ зафиксировало границы системы: ИС «Автоцентр Плюс» должна включать БД из 10 таблиц в 3НФ, клиентское приложение WinForms с ролевым доступом, REST API и подсистему отчётности. Требования раздела служат основанием для проектирования ER-модели (Раздел 3) и создания БД (Раздел 4).
